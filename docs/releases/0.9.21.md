# T刻 0.9.21

本次更新优化 AI 模型设置、可用资金说明，以及盈亏与总资产走势的查看体验。

## 盈亏与资产走势

- 图例支持点击显示或隐藏盈亏、总资产，默认只显示盈亏；坐标轴、事件标记和悬停内容同步切换。
- 支持累计盈亏与区间盈亏两种曲线口径。区间模式以所选首日日终为期初，首个点为 0，仅统计之后的收益并扣除转入转出影响；上方整段区间统计仍包含首日收益，界面已标明。
- 盈亏以 0 轴分色：盈利红色、亏损绿色；总资产保持蓝色，使用平滑曲线展示。
- 盈亏曲线显示 B / S / T：当天只有买入显示 B，只有卖出显示 S，买卖都有显示 T。
- 总资产线显示“入”“出”“入/出”资金变动标记，悬停可查看当天金额。
- 悬停浮层跟随鼠标定位，靠近窗口边缘自动避让；行情刷新保留当前日期，只展示该日数据，不再混入“合并的事件日期”。
- 浮层按盈亏、资产、当日流水分组，长内容可以滚动；点击标记可固定查看详情。
- 证券盈亏贡献表格随左侧图表高度填满可视区域，减少空白和悬停时的页面跳动。

## AI 设置与资金说明

- 模型设置改为紧凑列表和编辑侧栏，优化模型启停、默认分析模型、汇总模型及连接测试的操作反馈。
- 编辑内容尚未保存时提示处理，避免切换模型或关闭编辑器丢失修改。
- 将账户余额明确为当前剩余可用于买入的资金，AI 按买价、费用和整手规则计算数量，不再额外扣除假设的冻结资金。
- 保留多股共用预算、资金异常与缺失数据的处理；历史报告与账户数据保留。
