# T刻 0.8.2 — 单股 AI 分析入口与报告

本地开发与验收版本，尚未发布 GitHub Release。完整继承已整合的 v0.8.0 功能和 v0.8.1 SQLite Key 存储。

进入「自选与持仓」，单选证券并右键选择「AI 分析」，打开右侧抽屉。打开抽屉、历史报告不会调用模型；点击开始分析才采集公开数据并调用所选模型。

- 本次参与模型、汇总模型可临时修改，不改变设置中的默认值。汇总模型也可参与独立分析。
- 调用预估为参与模型数 + 1；独立调用失败可瞬时重试一次，格式修复额外最多一次，汇总可瞬时重试一次。单次最多20个参与模型、最多3个运行任务，配置保存数量不限。每次输出最多8192 token。
- 采集腾讯报价、分时、不复权日线（最近60根）、东方财富主力资金流及近30天巨潮股票公告列表。资金流日期不同于报价日期时排除。ETF 公告适配未接通时明确标示。
- 新闻提供公开检索链接与手动资料补充。公告仅标题和附件链接，不抓 PDF 正文；标题不能作为预测结论引用，需手动补充正文。任何缺失来源都会保存在快照中并显示。
- 收盘后今日窗口为复盘，休市日不预测今日收盘；交易日期用已核验2026沪深日历，覆盖期外停止而不猜日期。盘中报价明显延迟/收盘后只有早盘报价时不能发布今日方向。
- 每个模型接收同一冻结快照且不接收其他模型答案；汇总仅使用有效报告。结论先汇总，再展开各模型原始依据和资料引用；一个有效模型不标为多模型共识。结构与引用校验不等于预测正确，置信等级未经统计校准。
- 任务、快照、独立报告、汇总版本与调用尝试持久化到 SQLite。关闭抽屉不取消后台任务；取消明确操作，不复活状态。应用重启将未结束任务标为中断，不自动续发模型请求。
- 历史回看、重新分析与仅重新汇总可用。重新汇总使用历史冻结快照与有效报告，追加版本。批量分组分析、独立失败模型单独重试、PDF 正文采集等仍是后续阶段。

验证：487 项前端测试通过，70 项 Rust 测试通过（7项原有/手工测试忽略），类型检查和生产构建通过；公开源采集冒烟测试单独通过且未调用模型。代码审查的取消时序问题已修复，取消状态回归通过。实际原生入口验收记录见 docs/settings-design.md。
