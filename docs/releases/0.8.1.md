# T刻 0.8.1 — 本地 AI 设置整合版

本地开发与验收版本，尚未发布 GitHub Release。

- 完整包含已发布 v0.8.0 (`a8b04c2`) 的行情、状态栏、交易测算、成交对账和收益日历功能。
- AI 模型设置与费用设置统一为「设置」；支持多模型配置和默认参与/汇总模型。
- 支持模型版本下拉、自定义模型标识及从保存的接口获取模型列表。
- 修复 MiMo 输出长度参数及连接测试思考额度导致的空文本响应。
- 根据用户明确要求，API Key 保存到 SQLite 独立表 `ai_model_keys`，模型配置和 Key 原子保存。旧版钥匙串 Key 自动迁移；迁移失败保留旧引用，下次启动可重试，或编辑模型重新填写。原钥匙串条目保留，运行时从 SQLite 读取。
- 模型列表/配置 DTO、分析报告、日志和账本 JSON 导出不包含 Key。SQLite 数据库本身包含明文 Key。

版本来源：先在独立 AI 工作区与 v0.8.0 合并（`8eb72ea`），随后实现 SQLite Key 存储。旧 v0.6.0 AI 安装包不再作为当前交付版本。

验收：483 项前端测试、64 项 Rust 测试通过（6 项原有/手工测试忽略），TypeScript 类型检查及生产构建通过。包签名、DMG 校验和原生启动另行在设置设计记录中保存。
