# T刻 0.4.1

新增盈亏分析与收益日历，支持最近一月、半年、一年、开户至今及自定义区间。

- 展示盈亏金额、证券盈亏率、已实现盈亏、浮动盈亏变化、手续费、胜率与盈亏贡献。
- 收益日历提供全部、年、月视图；月视图默认最近十二个月倒序，仅展示周一至周五，默认窗口日历区域可完整显示六个月。
- 点击日期以弹窗查看收益明细，支持 Esc、关闭按钮及遮罩关闭，并保留日历位置。
- 证券盈亏率排除闲置现金和利息收入，月、年及区间按日收益率复利累计。
- 历史行情获取失败时自动切换备用不复权数据源，并保留严格的数据校验。
- 修复切换股票时顶部导航闪烁，优化交易录入、数量与价格调整和证券列表交互。

验证：387 项前端测试、18 项原生测试通过；年度行情联网测试及默认窗口日历、弹窗交互验证通过。

安装包：macOS Apple Silicon DMG、Windows x64 安装程序。
