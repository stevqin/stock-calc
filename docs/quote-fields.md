# 腾讯行情详情字段

当前支持沪深 A 股及 ETF。使用现有 `https://qt.gtimg.cn/q=...` 报价请求，不增加独立轮询。后端 `rawFields` 保留 GBK 解码后的完整顺序数组，包含空字段和未来新增字段。

字段命名参考腾讯官方行情页 `https://gu.qq.com/sh600519/gp` 加载的 `https://st.gtimg.com/quotes/hs-fund/bundle.13362df9.js` 中 `adaptHS` 映射（核对日期：2026-09-15）。价格、成交、估值、股本、阶段表现、ETF 净值按该映射呈现；市盈率字段 39 保留通用名称，52 为动态口径，53 为静态 LYR 口径。

- 成交额字段 57 单位为万元；市值 44/45 单位为亿元；成交/盘口数量为手；股本 72/73/76 为股。
- 字段 9–28 为买卖五档价量交替排列。
- 未明确含义的槽位不猜测名称，全部字段区以索引和“扩展字段”呈现原值；空值显示 `—`，数值零保留。
- 指标展示为便于阅读会换算万/亿单位及小数位；悬停和全部字段区可查原始精度。
- 旧缓存没有 rawFields 时使用现有 Quote 基础属性，未知指标显示缺失。新报价会替换旧快照。
- 保持现有证券与批量请求白名单、失败退避及后台刷新策略。

手动布局预览：启动 Vite 后打开 `/qa/quote-details/index.html`，使用独立示例行情，不访问个人账本。

## 指标颜色

- 量比以1为基准，大于1红色、小于1绿色，等于1或无有效值中性；仅表达成交活跃度。
- 委比及阶段涨跌幅正值红、负值绿、零中性；顶部52周涨跌幅继续使用历史行情计算结果着色。
- 外盘采用红色区分主动性买入成交，内盘采用绿色区分主动性卖出成交，不按二者数量谁多来变色。腾讯官方公开行情脚本中的内外盘展示也使用此方向颜色。
- 今开、最高、最低、均价、涨跌停价、52周高低价与昨收比较着色；缺少有效正数基准或无效指标值时保持中性。
- 市值、估值、换手率等无统一涨跌比较基准的数值保持中性；悬停保留原始数值，并注明有色指标的比较口径。

## 分时来源与缓存诊断（2026-10-22）

本机实测腾讯单日分时 `/appstock/app/minute/query` 返回 HTTP 501，而五日分时 `/appstock/app/day/query` 与股价接口仍正常。分时图改为优先从五日接口提取最新交易日的真实分钟序列，保留对应昨收、成交量和成交额；五日分时界面仍保留各交易日，不向历史序列补造价格点。

主接口请求或解析失败时才尝试单日备用接口。每次当日分时请求最多两次 HTTP 尝试，每次6秒，保持在前端15秒等待上限以内。两边失败时保留原曲线，并将两路服务名及 HTTP 状态/连接/接收错误写入更新状态。小图悬停展示数据来源、获取时间、最后真实点位时间及失败原因，缓存标记会随原生唤醒重新核对年龄。
