# AI 分析公开数据来源验证

验证日期：2026-10-13（Asia/Shanghai）。对应实施计划任务 1。

## 结论

本次已完成沪市股票、深市股票、沪市 ETF 的小规模列表与公告正文验证，以及 2026 年沪深官方休市安排核对。未调用模型，未改动账户或产品代码。

**技术可行性与生产启用分开判断。** 公告和日历具有可追溯的官方来源；东方财富新闻检索在三个样本上可返回元数据，但尚未确认第三方应用长期保存新闻摘录并向外部模型发送的使用范围。按已确认设计，暂不启用自动新闻正文采集。第一阶段来源验证有结果，完整新闻能力的启用条件尚未满足。

这一结果不等于“所有免费来源稳定可用”。仅验证当前网络、当天少量请求，没有做压力测试，没有确认服务级别或固定免费额度，也没有验证全部股票和 ETF。

## 实际请求协议

### 股票公告

1. `https://www.cninfo.com.cn/new/information/topSearch/query`，POST `keyWord`、`maxNum`，得到证券代码及机构标识；样本 600519 解析为 `gssh0600519`。
2. `https://www.cninfo.com.cn/new/hisAnnouncement/query`，POST 表单：`pageNum=1`、`pageSize=3`、`tabName=fulltext`、`column=szse`、`stock=<code>,<orgId>`、`seDate=<from>~<to>`。官网当前将沪深京股票映射到同一个 `szse` 栏目；需要时显式区分 `plate=sh`。
3. 用返回的 `adjunctUrl` 解析到 HTTPS 官方静态域名，只接收核验域名和路径；不拼猜 PDF ID。

依据是官网实际检索页引用的 `history-notice.js`，不是第三方库说明。网页脚本版本为 `v=20260710082532`，属于当前观测而非长期接口契约。正式解析必须二次核验返回代码。

成功样例：

- 000001：公告 ID `1225601360`，附件 `finalpage/2026-10-13/1225601360.PDF`；PDF 获取 HTTP 200，文本提取成功，实体一致。
- 600519：公告 ID `1225475868`，附件 `finalpage/2026-08-15/1225475868.PDF`；HTTP 200，文本提取成功。该公告超出正式 30 日窗口，只用于能力验证，不能自动成为当前分析依据。

空结果样例：已核验机构标识的 600519，在 2026-09-13 至 2026-10-13 返回 `totalAnnouncement=0`、`announcements=null`。扩大日期后成功，说明该空结果有身份核验支撑。

错误方法样例：GET 查询该 POST 接口返回 HTTP 500 和 HTML；错误栏目/仅关键词也可得到 HTTP 200 空列表。HTTP 200 不能单独证明证券正确或资料确实不存在。

### 沪市 ETF 公告

官网入口：[基金公告](https://www.sse.com.cn/disclosure/fund/announcement/)。实际页引用脚本 `search_fundInformation_2021.js`。

`https://query.sse.com.cn/commonQuery.do`，GET 参数：`sqlId=COMMON_PL_JJXX_JJGG_NEW_L`、`type=inParams`、`isPagination=true`、`pageHelp.pageSize=3`、`pageHelp.pageNo=1`、`pageHelp.beginPage=1`、`pageHelp.cacheSize=1`、`pageHelp.endPage=1`、`SECURITY_CODE=510300`、`START_DATE`、`END_DATE`、`DATE_DESC=1`。使用实际基金页面 Referer，无登录、Cookie 或访问控制绕过。

年内样本中的 `SECURITY_CODE` 为 510300，首条日期为 2026-08-29，PDF 为 `/disclosure/fund/announcement/c/new/2026-08-29/510300_20260829_2Q86.pdf`。HTTP 200，文本提取能确认基金管理人和基金代码。

ETF 深沪来源和字段不能强行统一：巨潮基金代码表未含本次沪市 ETF，关键词可返回其他证券，基金管理人公告还可能关联多个产品。无法确认关联时标注 unsupported 或身份不明确，不当作成功但无内容。

### 新闻检索

实际搜索页：[东方财富搜索](https://so.eastmoney.com/)。官网 `search_main.js` 采用 `search/jsonp` 和 `cmsArticleWebOld` 类型。

`https://search-api-web.eastmoney.com/search/jsonp`，GET `cb=sourceValidation`、`param=<JSON>`。JSON 包含 `keyword=<code>`、`type=["cmsArticleWebOld"]`、`client=web`、`clientType=web`、`clientVersion=curr`、`uid=""` 和 `param.cmsArticleWebOld={searchScope:"ALL",sort:"time",pageIndex:1,pageSize:3,preTag:"",postTag:""}`。

不带 `cb` 时三个样本均返回 HTTP 400；补齐官网 JSONP 参数后均 HTTP 200 且业务 code=0。JSONP 只能验证回调包裹后解析 JSON，不能 eval。

本次全窗口命中总数分别为 572、171、415；每样本仅读取 3 条。命中是关键词搜索，不是经过核验的证券归属：000001 样本含跨多家银行的报道，510300 样本含多只指数 ETF 的报道。后续必须区分直接个股事件、板块背景和仅文字提及。

未抓取新闻文章正文，仓库样例不保存新闻标题或摘要，仅保存字段清单、日期、媒体和链接，以记录协议和覆盖。不能据搜索摘要推断公告事实，不能把正文缺失标为完整资料。

## 时间精度与数据完整性

- 巨潮样例 `announcementTime=1791820800000` 转为本地是 2026-10-13 00:00:00。不能据此认定当天零点已经公开；本次只能验证公告日期，盘中截止判断应标为日期精度不足。
- 上交所 `SSEDATE` 只有日期，同样不能作为盘中精确公开时间。
- 东方财富 `date` 有秒值但响应没有时区声明；精度与时区是两件事。时区核验之前保留原始字符串并标注，不静默转换为已确认 UTC 时间。
- 三份 PDF 文本提取成功不代表扫描件都可处理；正文不可得时保留 titleOnly，第一版不要求 OCR。
- 本次模拟的正文不可得 fixture 明确标为 derivedFailureCase；不声称现场找到了一份真实无法提取的 PDF。
- 公告列表 `announcementContent` 为空：只拿列表时即使有 PDF 链接也没有正文，必须单独取得并提取 PDF。

## 使用范围与启用判断

- [东方财富服务协议](https://about.eastmoney.com/home/protocol)第六节涉及其内容及相关权利人的使用许可。网站可访问、接口无登录不足以确认第三方长期存储并发送给外部模型的使用范围。这是项目启用条件尚未核实，不在此作法律结论。
- [上交所法律声明](https://www.sse.com.cn/home/legal/)允许在其条件下为非商业目的浏览、下载，并区分向他人出售牟利等使用。非商业个人研究与未来发布应用不能视作同一个范围；对外发布前重新核实，不能把本次验证当作商业授权。
- 巨潮首页的免责声明主要涉及信息准确性和责任，并未给出本次需要的明确第三方 AI 处理授权。官方数据服务平台另有注册、文档与商城；本次没有取得正式 API 授权或永久免费条件证明。

生产启用前应为每个来源记录“取得方式、允许保留的资料范围、可否发送第三方模型及适用使用场景”。现有应用行情和资金流仅核对了代码复用位置，本轮没有重新验证其授权或全市场覆盖，不扩大原有数据权限解释。

## 后续影响与需要调整的范围

任务 2 的 DTO、仓储和任务 3 的模型网关不依赖某个新闻端点，可以继续开发。任务 4 需要保留来源能力开关，不能默认宣称自动新闻正文已经可用。

建议免费第一版优先实现已核验的公告、日历以及现有市场数据能力；新闻先显示可核验的来源线索，分析正文只接受用户主动提供且可用于分析的资料，或后续找到使用范围明确的免费渠道。此项改变了“默认自动结合新闻正文”的体验，需要用户确认后才能修改设计。也可以继续专项寻找允许自动分析和保存的免费新闻渠道，期间不假造新闻功能。
