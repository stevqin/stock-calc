# 盈亏分析

顶部「盈亏分析」与资金流水、费用设置同级。区间可选择最近一月、半年、一年、开户至今或自定义日期；滚动区间包含起止日，月末按目标月份最后一天处理。

## 收益日历

- 全部：每格一个年份，从最早账本记录年到当前年。
- 年：所选年份的十二个月，默认当前年。
- 月：默认展示含当前月在内的最近十二个月，倒序排列，最新月份位于左上角；选择月份后以该月为起点向前展示十二个月。常规窗口每行三个月、共四行；日期格高 50px，月份金额与盈亏率并排。默认 1380×940 窗口（扣除标题栏）滚动到日历区域后，可完整显示两行六个月。窄窗口自动调整为两列或一列。每个月历只展示周一至周五，隐藏周六、周日；月汇总仍包含周末入账的收益。
- 点击日期以居中弹窗查看证券盈亏、盈亏率、当日卖出盈亏、手续费和当天记录。弹窗支持关闭按钮、Esc 和遮罩点击关闭，内容较多时内部滚动；关闭后焦点回到对应日期，保留日历滚动位置。

日历与顶部分析区间独立；切换不保存账户、不触发导航禁用。未来、无记录、休市及数据不足分别展示。

## 统计口径

每日证券收益为日末市值减日初市值，加卖出净收入、减买入含费金额。区间总收益为每日收益之和，并包含利息、逆回购利息和其他收入。出入金、旧版期初资金不算收益；手续费已经计入，不重复扣除。

证券盈亏率沿用顶部今日收益率口径：每日证券盈亏 ÷〔日初持仓市值 + max(0, 当日买入含费金额合计 − 卖出净收入合计)〕。跨证券先合计净买入再取正值，排除闲置现金、出入金和利息等收入。月、年、区间按未舍入的每日收益率复利累计，最终显示两位小数；不把显示后的日百分比直接相加或连乘。缺失估值或存在无法计算的交易日时显示「—」；纯现金、空账本无证券收益率，无交易空仓日不影响有效区间的复利。整体概览、年月格子、月历标题、日格子和日详情均显示证券盈亏率。

卖出盈亏沿用账本 FIFO 和历史手续费，等于卖出净收入减去按 FIFO 匹配的买入成本，包含部分卖出和已经清仓的交易。账户层面先合计未舍入结果，再舍入到分；多只股票分别显示时可能存在分位舍入差异。浮动盈亏变化等于证券区间收益减区间卖出盈亏。

胜率为区间内结束的盈利持仓轮次数除以全部结束轮次数（包含持平）。计入完整轮次的成本和费用；同日清仓后再买入不拆轮次。当天收盘前不将零持仓标为已结束，未结束轮次不参与平均盈利、平均亏损与胜率。

历史日收益使用对应日期的不复权收盘价；当天有效报价可用于盘中估算。期初快照当天缺少日初基准、持仓行情缺失等情况显示未知，并列出区间内缺失日期。累计曲线在首个缺口处停止，不把未知收益拼成完整曲线。

历史行情按年度获取，包含前一年十二月用于基准；腾讯服务出现网络错误、HTTP 错误或解析失败时，自动切换东方财富日线接口（fqt=0 不复权），并统一校验证券、年度范围、日期及 OHLCV。两个来源均失败时才显示包含各来源原因的错误。历史交易过的已清仓证券也会获取。年度缓存与短期走势图缓存隔离，最多三个请求并发；「备份恢复 → 仅清理行情缓存」同时清除年度缓存，保留账本。
