# AI 提示词和结论展示更新

## 新增要求的口语版

### 价格编号直接对应价格

操作建议里用到的价格，都要说清楚编号和实际价格，还要说明它是什么价位，例如昨收、当天高点或近期低点。不能只写“到L2再操作”，让我自己猜L2是多少。价格以本次保存的行情资料为准，不能编造编号或价格。

### 明确判断企稳和动能不足的方法

不要只说“下跌企稳”“反弹放量”“上涨没力气”。要说明看哪个价位、看多长时间或几次表现、价格要出现什么变化；如果还需要看成交变化，也要有对应资料。

企稳条件可以说明连续几根分时K线不再创新低、后根收盘抬高等；动能不足条件可以说明触及压力价后几次冲高未创新高、随后回落等。这些是待观察条件，不代表已经发生。现有资料无法核验时，要指出缺少什么，不编造量能或指标。

买入或买回步骤应与企稳条件一致；卖出步骤要说明适用的动能不足或风险条件。汇总保留原报告的条件，不重新编写判断事实。

### 首先让我看懂关键动作

结论页面先显示四项：现在怎么做、什么价卖多少、什么价买多少、继续持有或保留多少底仓。买卖步骤仍是有条件的预案；未触发前有持仓则先持有，未持仓则先等待。

没有买入或卖出步骤，就直接写“暂不买入”或“暂不卖出”。不能因为切换查看一个备选方案，就把它误显示为当前首选。

## 专业提示词与程序对应

- 独立分析增加对价格编号和冻结价格对应的说明，新增 `executionPlan.signalConditions.stabilization` 和 `weakening` 两条条件。
- 新快照标明必须包含条件；程序检查字段、长度及出现的L编号是否存在。它不验证自然语言推理质量，也不表示实时行情已经满足条件。
- 汇总仍只选择已有完整预案，复制原信号条件，避免改写原交易价格、股数及条件。
- 页面直接显示价格编号对照、两条确认条件及每类建议的触发/停止条件；中长期资料不足时不以短线信号替代基本面。
- 四项关键动作取自已校验的首选分支。旧报告可以显示其原有买卖步骤及价格对照，新条件需重新分析后生成。
