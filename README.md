## 开始使用

1. 打开 `src-tauri/target/release/bundle/macos/T刻.app`，或安装 `src-tauri/target/release/bundle/dmg/T刻_0.3.1_aarch64.dmg`。
2. 新账户从空账本开始，**没有初始化资金步骤，也不会自动产生10万元**。通过右上角「＋ 资金流水」补录实际转入、转出、国债逆回购利息、账户利息或其他收入，填写上海时间及备注。
3. 从自选选择股票或ETF，首次添加后本机记忆名称、代码、市场与手动确认的类别。行情刷新不会覆盖手工输入。
4. 在「录入历史成交」填真实发生时间、成交均价、数量。可以逐笔补录过去的买入和卖出，数量不必相同；系统按时间重算持仓、资金与FIFO成本。
5. 手续费可选「按交割单填写实际手续费」，分别录佣金、印花税及过户费；也可按确认过的独立费率估算。**ETF最低佣金为0（免5），实际ETF佣金率留空待用户填写，不沿用股票费率。** 股票万2.5、最低5元仅为示例。
6. 如果不准备补齐更早的买卖，可为该证券录入一次期初持仓快照，包括数量、成本、当时可卖数量和日期。快照时间必须早于该证券首笔买卖，不能与更早买入重复记账；可先记录买卖，再补更早的期初快照。
7. 下方「做T测算」是独立预演，不入账；「资金流水」「成交记录」「我的持仓」用于核对。账户备份可导出JSON、校验并确认恢复。

界面固定在窗口内，长表格、自选、录入表单、设置各自在面板内滚动。浏览器预览与桌面账户分开存储；浏览器不接实时行情，不用假图表填充。示例自选不是持仓或证券推荐。

## 修改、删除历史记录

「成交记录」「资金流水」每行右侧提供修改、删除，包括期初持仓、旧版迁移余额。可修改时间、买卖方向、价格、数量、实际费用、备注，或资金流水的类型/金额。所属证券不可直接切换；证券录错需先处理依赖的后续成交，再删除重录。

弹窗先展示全账户资金、净本金、FIFO已实现、利息及该证券持仓/成本的前后对比。估算手续费使用本条记录保存的历史费率，不使用当前设置；实际费用保留填写值，改价或改数量时需同步核对交割单。未改时间时保留原毫秒，同一时间维持原记录顺序。

修改或删除后全账本按时间回放。如果导致后续卖出历史持仓不足，会阻止保存，原记录不变；不会级联删除后续记录或补造持仓。现金历史不足仍只是待对账提示。删除必须二次确认，取消不写入；保存失败不更新内存。建议操作前导出备份，删除后可用该备份整账户恢复；桌面数据库另保留最近20个旧修订，不提供单条撤销按钮。

## 账务口径

- 账面资金：转入 − 转出 + 利息等收入 − 买入总支出 + 卖出净收入（另含旧版迁移余额）。缺少现金历史时允许负值，并提示待核对，不虚构资金来源。
- 净本金：转入 − 转出 + 期初持仓成本（另含旧版迁移余额）。**转入不是利润，转出不是亏损；利息不增加净本金。**
- 国债逆回购仅录入**实际到账净利息**；不跟踪本金冻结、解冻、期限或计息。返还本金不要重复记成收入；账面资金不等于券商可取/可用资金。
- 持仓数量：期初数量 + 买入数量 − 卖出数量。卖出时历史持仓不足仍阻止入账，需先补更早的买入或期初持仓，不编造FIFO成本。
- FIFO已实现收益：卖出净收入 − 卖出的FIFO批次成本。买入费用进入成本。利息和资金转账都不改变股票成本或股票已实现收益。
- 持仓浮动盈亏：参考价 × 剩余数量 − 剩余FIFO成本，未预扣卖出费。任一持仓缺报价时，总资产/合计浮盈显示不完整，不能把缺价视作0。
- 当日配对价差收益：同日买卖按各自成交顺序配对，费用按数量分摊。此项不同于FIFO已实现收益，**不能相加；不等量交易的现金流也不是利润**。
- 做T摊薄成本：本持仓批次累计净投入 ÷ 剩余数量，可为负。同日清仓买回延续批次，日终清仓后再次买入重启批次；不保证与券商显示一致。
- 历史记录按发生时间重放；同一时刻先处理资金流水，再按录入顺序处理成交。不支持未来记录。负现金提示只是账面检查，不证明历史券商交易实际可执行。
- 历史成交不再用T+1规则阻止用户录入已成交事实，但仍校验总持仓。可卖数量是按上海日期隔日解锁的估算，未接入交易日历。ETF类别与回转规则需按具体证券手动确认。

## 费用与价格

decimal.js十进制运算，各费用分别四舍五入到分。估算佣金为成交额×费率与最低佣金的较大者，按含规费口径，不重复叠加规费。每笔保存实际费用或当时的估算费率，之后改设置不追改历史。

股票默认卖出印花税0.05%、双向过户费0.001%；ETF默认两项为0，均允许校准。按实际交割单为准。历史记录允许正整数数量（含零股）、最多6位成交均价；做T预演仍按100整数倍及股票0.01元 / ETF0.001元报价档位。

原计划数值样例纠正：默认股票费率，10元买100股，10.11元卖出，买费5.01、卖费5.52、净利润**0.47元**；10.10元卖出亏**0.53元**；最低保本价10.11元。不是原计划的0.29 / −0.71。

反推价格搜索区间为一个档位至100万元，离散搜索并完整复核费用；配对收益未舍入前≥0为保本，≥0.01为开始盈利，无可行档位明确提示。预演假设按输入价成交，不保证成交、滑点或盈利。

# 资金流与成交BS点 · 2026-08-31

- 日K（含不复权模式）同一证券同一天既买又卖，合并为蓝色T标记，先后顺序及数量是否相同均不影响判断；悬停按成交时间展示每笔买卖方向、价格、数量。只有买入显示B，只有卖出显示S，分时和五日分时仍各自标注B/S。T仅表示同日买卖，不表示盈利或已配对数量。
- 腾讯继续提供价格、分时、五日分时与日K；主力净流入增加东方财富独立数据通道，每30秒刷新，失败退避，隐藏暂停。该通道本次真实联网验收连接失败，尚未确认当前网络可用，缺失显示“—”。缓存失败保留值带 `*`，悬停查看数据时间、来源与错误；与报价交易日不一致时不显示。

- 双击证券后的三种图表显示真实记录的B买入、S卖出，悬停看时间、原始成交价、数量；同一分钟/同一日同方向合并标记，保留全部成交明细。修改或删除成交即时重画。不把建仓快照当成真实成交，不生成建议买卖点。
