# T刻 0.9.23

本次更新新增每笔成交后的持仓成本，优化历史成交和股票详情的交易记录，并修复开盘期间股价更新、分时图却一直显示缓存的问题。

## 新增与优化

- **每笔成交后的持仓成本**：历史成交和股票详情的交易记录新增“持仓成本”，显示该笔交易完成后的摊薄成本，包含已记录的交易费用和做 T 对成本的影响；无剩余持仓时显示“—”。筛选记录不会改变历史成本，修改或删除成交后会重新计算。
- **交易记录更紧凑**：日期、时间分两行显示，缩窄时间列；股票详情中将费用合计和佣金合并展示，费用合计在上方突出显示，佣金作为下方补充。交易类型采用更简短的名称。
- **持仓阶段可折叠**：股票详情中的各个交易阶段可独立展开或收起，方便查看某一轮持仓和成交。
- **行情指标配色更清楚**：为量比、委比、内盘、外盘及部分价格指标增加红绿配色，并提供比较口径说明；量比以 1 为基准，价格指标与昨收比较，内外盘颜色用于区分成交方向。

## 分时刷新修复

- **修复分时图长时间停留在缓存**：原单日分时接口可能返回 HTTP 501，而报价接口仍正常，导致股价变化但走势图不更新。现优先从正常响应的五日分时接口提取最新交易日的真实点位，原单日接口作为备用。
- **失败后保留走势并继续刷新**：任一接口不可用时尝试备用接口；两个接口均失败时保留上次成功的数据，等待下一轮自动刷新。分别限制请求耗时，避免卡住刷新队列。
- **缓存原因可查看**：鼠标悬停在表格分时小图上，可查看数据来源、更新时间、最新点位时间及具体刷新错误；缓存状态也会随时间更新。
