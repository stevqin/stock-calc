# 0.9.8：局部方案校验与紧凑报告视图

模型输出先检查全局格式、五类模块必填字段和枚举、资料引用及时间窗口，再分别校验做T、减仓、加仓三个量化分支。局部违规分支标为不可用，移出可执行清单并明确显示原因；其他通过检查的分支和分析结论保留。不会合并分批买入、改变价格或股数、自动改选其他首选方案。

首次及格式修复输出继续原样保存。局部分支问题不触发模型格式修复；全局JSON/模块/引用错误仍拒绝，已有一次格式修复上限保持，不无限重试。汇总引用不可用的操作结论时也标记不可用；选择已拒分支时仅等待，不能恢复其订单。全局格式错误不能通过不可用转换被掩盖。

结构工具按本轮约束限制不可行分支的状态和步骤数量；减仓/加仓最多一笔，做T两笔，不合并模型给出的多笔交易。提示说明实际与允许的步骤数量。

报告顶部提供操作清单、综合结论、独立分析三个入口，切换时直接展开对应内容；价格22px、股数20px，正文与卡片间距缩小，保留L编号、执行标准、依赖和取消条件。窄屏检查宽度390px。
