# 盈亏分析历史行情（SQLite）

年度历史行情已改为优先读取本机 `simulation.sqlite3`，不再把新数据写入 localStorage。有效旧缓存首次读取时事务写入数据库，写入成功才删除旧键。持久化失败会明确报错，避免误认为已保存。

## 表与加载策略

- `analysis_daily_bars`：以证券、日期为主键保存不复权OHLCV、来源和获取时间；较旧响应不会覆盖新价格，部分刷新不会删除已有日线。
- `analysis_history_years`：证券、年份的年度元数据；每年包含上一年12月，以供年初收益基准。
- `analysis_suspensions`：有公开公告依据的停牌日及估值参考日期，独立于成交日线保存。分析时引用已知收盘价，绝不伪造停牌日成交行情。
- 页面只加载账本证券涉及的年份，已清仓证券不会继续索取清仓年份之后的数据，也不请求首次交易之前的年份。
- 完整往年缓存持续复用；当年跨上海日期后刷新，16:00后再次加载时更新当天盘中缓存。缓存失效后的网络请求仍以年度为单位。
- 同一证券、年份的进行中请求合并，最多3个并发。网络失败时可继续使用已保存的历史日线；显式“补充历史行情”会报告联网失败。
- 清理行情缓存会清理年度元数据和日线；已核验的停牌公告依据独立保留，账户数据不受影响。
