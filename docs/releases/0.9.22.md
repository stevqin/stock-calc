# T刻 0.9.22

本次更新重点修复 Mac 版走势图长时间运行后停止刷新的问题，并提供 Mac、Windows 两个平台的安装包。

## 修复与改进

- **走势图恢复持续更新**：修复股价仍在变化，但分时、五日分时和表格中的分时小图可能停止刷新的问题。
- **休眠与窗口恢复更可靠**：Mac 休眠唤醒、最小化或重新打开窗口后，通过系统窗口状态恢复图表刷新，避免页面可见状态没有同步导致刷新中断。
- **请求卡住后可自动恢复**：走势图请求超过 15 秒未返回时，释放被占用的请求队列，保留上一次成功的曲线，等待后续刷新。
- **避免旧数据覆盖新走势**：已超时请求即使稍后才返回，也不会覆盖较新的图表数据。
- **保持合理重试间隔**：失败后等待再试，避免窗口唤醒信号触发密集重复请求；屏幕外的表格小图不会因周期唤醒而加载。

## 安装包

- **Mac**：`Tke_0.9.22_darwin_aarch64.dmg`，适用于 Apple Silicon Mac（M1 及后续芯片）。
- **Windows**：`Tke_0.9.22_windows_x64_setup.exe`，适用于 Windows 64 位系统。
- **校验文件**：`SHA256SUMS.txt`，用于核对两个安装包的完整性。

## 数据与兼容性

本次更新无需修改账户和模型配置，保留交易记录、历史分析报告及已有设置。刷新问题主要针对 Mac 修复；Windows 安装包同步包含通用的请求超时恢复逻辑。

- 回归覆盖两小时模拟刷新、页面错报隐藏、屏幕外小图、四个请求同时无响应、休眠后超时恢复、旧响应迟到及缓存保留。
- 600 项前端测试、158 项 Rust 测试通过；17 项实网或私有样本测试按原配置跳过。
- TypeScript 检查和前端生产构建通过；Mac、Windows 安装包由 GitHub Actions 构建。
