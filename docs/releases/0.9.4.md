# T刻 0.9.4

个股 AI 报告新增具体价位和股数的条件预案，默认保留底仓、优先评估先卖后买做 T；结论页面优先显示当前动作，减少辅助资料占用。

## 新增与改进

- 在设置中配置独立模型和汇总模型，支持 MiMo 及兼容接口；结合本股持仓、本轮交易、费用和本机账本余额生成报告。
- 今日、本周、稳健、短期/做 T、中长期五类建议使用固定结构，分别说明触发、失效条件及数量、资金依据。
- 应用先校验行情参考价、可卖数量、保留底仓、单轮上限和双向费用，再提供做 T 候选组合；模型判断适用条件，应用生成与交易步骤一致的量化主标题。
- 区分直接加仓与先卖后买的资金要求；买回必须等待卖出成交及券商可用回款确认。T+1 买回不会增加当日可卖数量。
- 分别显示“只卖出、尚未买回”和“两步完成”后的持仓、余额及摊薄成本变化。
- 结论置顶，五类建议通过标签切换，账户、交易、模型原文和执行记录默认折叠。
- 支持报告删除、回收站、恢复及单独确认永久删除，历史查看与恢复不调用模型。
- 精简重复输入，区分连接、等待响应头及等待生成超时；分别保留首次与格式修复输出，错误显示具体字段，格式修复最多一次。

## 使用说明

旧报告保留原有内容。重新分析才会生成新的量化预案；重新汇总使用原冻结资料。价位为已采集资料的观察参考，成交前需核对行情、可卖数量和券商资金。应用不连接券商账户，也不自动下单。

当前密钥按用户配置保存在本机 SQLite，复制完整数据库会包含密钥。报告和账本 JSON 导出不包含密钥。
