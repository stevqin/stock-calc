## 为什么开发 T刻

这个工具来自一个很实际的问题：小资金账户频繁买卖或做 T 时，看起来有价差，并不代表真正有利润。

佣金最低收费、印花税、过户费和买卖数量都会影响最终结果。尤其在交易金额不大时，几分钱的价差可能完全覆盖不了双边费用；如果买卖数量不一致，还会改变持仓数量、资金占用和摊薄成本。只盯着买入价和卖出价，很容易出现“操作很多，成本反而更高”的情况。

我开发 T刻，是希望在下单前先回答几个具体问题：

- 按当前费率，这次计划交易到底有没有利润空间？
- 固定买入价后，至少卖到什么价格才能保本或达到目标利润？
- 先卖后买时，最高可以在什么价格回补？
- 相邻几个报价档位分别对应多少净收益，安全价格带在哪里？
- 买卖数量不一致时，实际配对了多少，净增仓或减仓多少？
- 做完这次 T 后，剩余持仓数量、净投入和摊薄成本会变成多少？

T刻把这些问题做成了可反复调整的测算工具，同时提供本地证券账本，帮助核对历史成交、资金流水、FIFO 成本、当日收益和当前持仓轮次收益。

**T刻只负责计算、记账和复盘，不连接券商账户，不读取券商持仓，也不会自动下单。**

## 核心能力

### 1. 做 T 正算：计划输入后立即看结果

分别输入计划买入价、卖出价、买入数量和卖出数量，T刻会自动计算：

- 买入总支出、卖出净收入及完整双边手续费；
- 实际配对数量、配对毛收益、分摊费用和配对净收益；
- 未配对部分造成的净增仓或净减仓；
- 两笔交易合计现金流；
- 测算后的持仓数量、持仓净投入和摊薄成本；
- 按当前参考价估算的持仓市值、持仓收益及收益率。

买卖数量不必相同。系统只把可配对的部分计算为做 T 收益，未配对部分明确列为增减仓，避免把现金流误当成利润。

### 2. 做 T 反推：找到保本价和目标利润价

当你只确定一侧价格时，可以让 T刻反推另一侧价格：

- **固定买价 → 最低卖价**：至少卖到多少才能保本或达到目标净利润；
- **固定卖价 → 最高回补价**：先卖后买时，最多以什么价格回补；
- **保本档位**：完整计入佣金、印花税和过户费后，配对净收益不低于 0；
- **开始盈利档位**：配对净收益达到至少 0.01 元的首个合法报价；
- **目标利润价**：输入目标配对净利润后，反推满足目标的价格；
- **价格阶梯**：展示保本价附近多个报价档位及对应净收益，直观看到价格带。

反推不是简单地给买卖价相减，而是逐个合法报价档位搜索，并用完整费用函数复核。股票按 `0.01` 元档位，ETF 按 `0.001` 元档位计算。

### 3. 手续费进入每一次测算

T刻使用十进制运算处理金额，各项费用分别计算并四舍五入到分：

- 佣金：成交额 × 佣金率，并考虑最低佣金；
- 印花税：仅卖出方向收取，费率可配置；
- 过户费：按配置的双向费率计算；
- 股票与 ETF 使用独立费率配置；
- 历史成交既可保存实际交割单费用，也可保存当时的估算费率。

费率设置只是测算参数，实际费用应以券商交割单为准。不同券商、账户和品种的收费标准可能不同，首次使用前请先校准。

### 4. 本地证券账本与持仓重算

除了下单前测算，T刻也可以作为个人证券账本使用：

- 记录买入、卖出和期初持仓；
- 记录资金转入、转出、国债逆回购利息、普通利息及其他收入；
- 按发生时间回放全部记录，自动重算资金、持仓和收益；
- 使用 FIFO 批次跟踪持仓成本和卖出已实现收益；
- 计算当前持仓轮次的净投入与做 T 摊薄成本；
- 修改或删除历史记录前预览全账户重算影响；
- 当修改会造成后续卖出时历史持仓不足时阻止保存；
- 支持 JSON 备份、校验、整账户恢复和最近修订恢复。

### 5. 自选、行情与交易复盘

- 自选支持中文名称、完整拼音、拼音首字母和部分证券代码搜索；
- 支持全部自选、我的持仓、盈利、亏损及自定义分组；
- 表格可配置字段、顺序和排序，并在本机保存工作区状态；
- 展示最新价、涨跌幅、5 日涨跌幅、量比、换手率、振幅、成交量和流通市值等指标；
- 支持分时、五日分时、日 K 和表格内迷你走势图；
- 在图表上标记账本中的 B（买入）、S（卖出）和同日 T 记录；
- 双击证券打开详情，可查看行情、收益明细、做 T 测算和交易记录；
- 行情与账本分开存储，公开行情缺失时不会把缺失值当作 0。

公开行情可能延迟、缺失或不可用，只适合作为测算参考。真实成交价格、可卖数量和交易规则请以券商为准。

## 一个典型使用流程

1. 在「费用设置」中填写自己账户真实的股票与 ETF 费率。
2. 添加关注的证券，确认证券类别和 T+0 / T+1 回转规则。
3. 双击证券进入详情，打开「做 T 测算」。
4. 在「正算」中输入计划买卖价和数量，观察配对净收益、现金流及持仓变化。
5. 切换到「反推」，固定准备成交的一侧价格，并将目标利润设为 `0` 查看保本价。
6. 再设置期望的目标净利润，查看最低卖价或最高回补价，以及附近的价格阶梯。
7. 核对可用资金、实际可卖数量、涨跌停和盘口后，再自行决定是否在券商端操作。
8. 成交后按交割单把真实价格、数量和费用录入账本，用于后续复盘。

测算结果不会自动写入成交记录，避免把交易计划误当成已经发生的交易。

## 计算口径

### 做 T 配对收益

当买卖数量相同时：

```text
配对净收益 = 卖出净收入 - 买入总支出
```

当买卖数量不同时，只对两边较小的数量计算配对收益，并按每股/份费用分摊：

```text
配对数量 = min(买入数量, 卖出数量)
配对净收益 =（每股/份卖出净收入 - 每股/份买入总支出）× 配对数量
净持仓变化 = 买入数量 - 卖出数量
```

完整两笔交易的现金流仍会单独展示。现金流为正不等于做 T 盈利，增减仓也不应被混入配对利润。

### 保本与开始盈利

- 保本价：配对净收益的精确值不低于 `0` 的首个合法报价档位；
- 开始盈利价：配对净收益不低于 `0.01` 元的首个合法报价档位；
- 目标利润价：配对净收益不低于用户目标值的首个合法报价档位。

反推搜索范围为一个合法报价档位至 100 万元；如果范围内不存在可行解，会明确提示，而不是给出伪造价格。

### 账本与持仓

- 账面资金 = 转入 − 转出 + 利息等收入 − 买入总支出 + 卖出净收入；
- 净本金 = 转入 − 转出 + 期初持仓成本；
- FIFO 已实现收益 = 卖出净收入 − 对应 FIFO 批次成本；
- 持仓浮动盈亏 = 当前参考市值 − 剩余 FIFO 成本；
- 做 T 摊薄成本 = 当前持仓轮次累计净投入 ÷ 剩余数量；
- 当日收益 = 当前/日末市值 − 日初市值 + 当日卖出净收入 − 当日买入总支出。

转入资金不是利润，转出资金不是亏损；利息不进入股票成本。日终清仓后再次建仓会开始新的持仓轮次，同日清仓后买回仍延续当前轮次。

更完整的边界与验收口径见 [VALIDATION.md](./VALIDATION.md)。

## 安装与运行

### 当前支持范围

- macOS 12 及以上；
- 当前仅在 Apple Silicon Mac 上完成实机验证；
- 应用采用本机 ad-hoc 签名，未做 Apple 公证；
- 暂未提供 Windows 安装包和自动更新。

当前仓库未附带可直接下载的安装包，需要从源码运行或自行打包。

### 从源码启动

需要准备：

- Node.js 22 或更高版本；
- Rust 工具链；
- macOS 上的 Xcode Command Line Tools。

```sh
npm ci

# 浏览器开发预览
npm run dev

# Tauri 桌面开发模式
npm run desktop
```

浏览器预览与桌面应用使用不同的存储空间。浏览器模式主要用于界面开发，不具备完整的桌面本地数据库与原生行情能力。

### 构建与打包

```sh
# TypeScript 检查与前端生产构建
npm run build

# 构建 macOS .app 和 .dmg
npm run package

# Rust 测试
cargo test --locked --manifest-path src-tauri/Cargo.toml
```

打包产物位于：

```text
src-tauri/target/release/bundle/macos/
src-tauri/target/release/bundle/dmg/
```

## 数据存储与隐私

桌面账本默认保存在：

```text
~/Library/Application Support/com.stev.tcalculator/simulation.sqlite3
```

- 账户、持仓、成交、资金流水、费率和工作区设置均保存在本机；
- 不需要登录，不提供云同步，不上传账本和持仓；
- 在线证券搜索只发送用户输入的搜索关键词；
- 在线行情只发送证券市场与代码；
- JSON 备份包含完整账户信息，请像保护券商交割单一样妥善保管；
- SQLite 使用事务提交、WAL 和修订冲突检查，并保留最近 20 个旧修订。

行情请求仅访问代码中限定的公开数据域名，不开放任意 URL 代理。行情实现与安全边界可查看 `src-tauri/src/search.rs`、`charts.rs` 和 `fund_flows.rs`。

## 已知限制

- 不连接券商，不执行委托，不验证实际成交概率；
- 不检查账户可用资金、真实可卖数量、涨跌停、停牌或盘口流动性；
- 可卖数量按上海日期隔日解锁估算，未接入正式交易日历；
- 不自动处理分红、送股、配股、拆股、合股等公司行动；
- 当前主要支持沪深 A 股和 ETF，不包含融资融券、北交所、可转债和期权；
- ETF 是否支持 T+0 需按具体品种人工确认；
- 国债逆回购仅登记实际到账净利息，不跟踪本金冻结与到期释放；
- 公开行情存在延迟、复权差异、缺失或服务不可用的可能；
- 做 T 测算使用用户配置费率，最终结果应以真实成交和券商交割单为准。

## 风险提示

T刻是个人记账与测算工具，不构成任何投资建议、收益承诺或交易信号。保本价只表示在给定价格、数量和费率假设下，计算结果达到费用口径上的保本；它不包含滑点、价格跳空、委托未成交、流动性、交易规则变化及其他市场风险。

在券商端提交任何订单前，请自行核对证券规则、账户资金、可卖数量、实际费率和委托价格，并独立承担交易决策与结果。
