# AI 第一版：模型配置与报告存储阶段交付

日期：2026-10-13。阶段 B 完成，模型设置页已提前交付。

## 已实现

- 主工作区「AI 设置」入口；新增、编辑、启用、禁用与删除多个模型配置。
- 自定义 OpenAI 兼容基础地址、模型标识、密钥；默认参与模型与默认汇总模型。
- macOS Keychain / Windows Credential Store 原生适配。SQLite 仅保存配置与凭证引用；更换 API 主机时已有凭证不能自动沿用，必须显式输入新密钥。
- 替换密钥先写新的安全存储条目，再保存配置；失败不改旧配置。旧凭证删除失败写入清理队列；后续保存配置重试，删除失败状态明确提示。
- 测试连接：短请求验证兼容响应；提示可能计费并显示成功时实际调用数。浏览器预览禁止保存真实密钥，不读取原生配置。
- 模型网关：HTTPS 或显式本机 HTTP、禁止重定向、响应大小限制、120 秒默认超时、瞬时错误最多一次重试，支持 Retry-After 秒数与 HTTP 日期。
- 全局三路、同主机两路队列；等待与在途请求可由调用方取消。格式修复调用可禁用额外重试，后续编排据此遵守总次数上限。
- 独立 AI 数据表：幂等任务、冻结资料和证据、模型报告、追加汇总版本、历史过滤与分页、引用安全删除；迁移保留既有账本及历史行情。
