# 腾讯行情详情字段

当前支持沪深 A 股及 ETF。使用现有 `https://qt.gtimg.cn/q=...` 报价请求，不增加独立轮询。后端 `rawFields` 保留 GBK 解码后的完整顺序数组，包含空字段和未来新增字段。

字段命名参考腾讯官方行情页 `https://gu.qq.com/sh600519/gp` 加载的 `https://st.gtimg.com/quotes/hs-fund/bundle.13362df9.js` 中 `adaptHS` 映射（核对日期：2026-09-15）。价格、成交、估值、股本、阶段表现、ETF 净值按该映射呈现；市盈率字段 39 保留通用名称，52 为动态口径，53 为静态 LYR 口径。

- 成交额字段 57 单位为万元；市值 44/45 单位为亿元；成交/盘口数量为手；股本 72/73/76 为股。
- 字段 9–28 为买卖五档价量交替排列。
- 未明确含义的槽位不猜测名称，全部字段区以索引和“扩展字段”呈现原值；空值显示 `—`，数值零保留。
- 指标展示为便于阅读会换算万/亿单位及小数位；悬停和全部字段区可查原始精度。
- 旧缓存没有 rawFields 时使用现有 Quote 基础属性，未知指标显示缺失。新报价会替换旧快照。
- 保持现有证券与批量请求白名单、失败退避及后台刷新策略。

手动布局预览：启动 Vite 后打开 `/qa/quote-details/index.html`，使用独立示例行情，不访问个人账本。
